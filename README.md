# 🚀 Passion-Hub

A Python Flask web application designed to connect people, share experiences, and build communities around common interests.

## ✨ Features

- 🔐 User Registration & Login
- 🔑 Forgot & Reset Password
- 👤 User Profile
- 🌐 Community Selection
- 📊 User Dashboard
- 💾 SQLite Database
- 🎨 Responsive Web Interface

## 🛠️ Technologies Used

- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript
